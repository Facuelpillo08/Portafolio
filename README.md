# Facundo Acosta — Portafolio Web

Sitio web y portafolio personal interactivo desarrollado con **React**, **Vite** y **Tailwind CSS**, diseñado con estética editorial moderna y efectos de profundidad parallax 3D.

---

## 🚀 Tecnologías Utilizadas

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **GSAP** (Animaciones y transiciones)
- **Lucide React** (Iconografía)

---

## 🛠️ Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Facuelpillo08/Portafolio.git
   cd Portafolio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en entorno de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
